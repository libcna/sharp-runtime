# Audit findings index

This index is populated only after a report contains an evidence-backed
finding.  Each entry links to the owning per-file report and gives a stable
identifier (`SR-AUD-###`), severity, status, and concise remediation target.
`confirmed` means the finding remains open; `remediated` means its original
evidence is retained but a bounded repair and its closure gates have passed.
`confirmed (design-complete)` is a qualifier, not a separate status: the
finding is still open and still counted as `confirmed`, but a completed
design-only ticket has recorded the selected repair and its blocked or inactive
implementation ticket.
